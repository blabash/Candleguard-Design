# Core Loop

Candleguard's core loop is a single-lane PvP push where kobold champions fight, escort, scavenge, mine, and break enemy defenses.

## Match Loop

1. Spawn as a named kobold champion.
2. Push the contested underground lane with allied creeps.
3. Fight enemy champions over space, timing, and resources.
4. Use abilities to clear waves, protect workers, punish mistakes, and pressure structures.
5. Capture, mine, or contest Shinies and other objectives.
6. Convert advantages into stronger pushes.
7. Breach the enemy base or final underground objective.

## Player Counts

The current target modes are:

- 1v1
- 2v2
- 3v3

The lane structure should stay compact enough for small-team combat to remain readable and active.

## Design Feel

Matches should be fast to understand but rich in decisions:

- when to fight
- when to push
- when to protect the wave
- when to dive into side objectives
- when to spend resources
- when to abandon a lost tunnel

The player should always feel that the battlefield is an underground workspace being violently misused.

## Relationship to Unreal Project

The Unreal project can remain internally named `ProjectGenesis` while this design repository uses the public-facing working title `Candleguard`.
