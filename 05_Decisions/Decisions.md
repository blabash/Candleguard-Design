# Decisions

This file records design decisions so the project does not lose its memory.

## 2026-09-12

- Working title changed from Digfight / Project Genesis naming exploration to `Candleguard`.
- `Candleguard` is preferred as the game/franchise title; `Candleguard Champions` remains useful as internal language for the roster.
- The Unreal project may remain named `ProjectGenesis` internally for now.
- Create a separate design repository named `Candleguard-Design`.
- Local design repository path: `D:\GameDev\Design\Candleguard-Design`.
- The design repository is the source of truth for lore, design intent, concept art, open questions, and decisions.
- Playable characters are unique named kobold champions.
- Core mode is a single-lane PvP push supporting 1v1, 2v2, and 3v3.
- Kobolds constantly dig, expand, scavenge, engineer, tame beasts, and fight over underground resources.
- Candleguard kobolds should be dangerously competent, not merely funny miners.
- `Shinies` are the crude kobold term for valuable underground materials.
- A hidden mycelial network subtly empowers underground life and kobold capability.
- Most kobolds are unaware of the hidden mycelial network.
- The Deep and the Mouth Below are key mythic/horror elements.
- Candles are a recurring visual and lore motif.
- Candles are ritual safety equipment that react to underground danger, not only a decorative joke.
- Avoid copying Warcraft-specific kobold expression, catchphrases, candle gags, silhouettes, lore, or dialogue.
- Preferred character rendering combines realistic materials with exaggerated/cartoon proportions.
- Humanoid characters should try hard to look formidable but retain accidental charm.
- Creep design principle: ask what job the unit performed before kobolds sent it into battle.
- Rat Scavenger and Mole Bruiser should incorporate the candle motif.
- Use Git LFS for concept art and image-heavy assets.
